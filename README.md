## Deskripsi Repositori
Repositori ini berisi penyelesaian tugas Pemrograman Dasar TLS 2026 yang terdiri dari dua fase:

1. **Fase 1 (Perancangan Logika)**: Dokumen PDF berisi Pseudocode, dan Penjelasan Logika untuk Problem 1 dan Problem 2.
2. **Fase 2 (Implementasi C++)**: Program C++ asli yang diimplementasikan sesuai dengan rancangan logika Fase 1 tanpa mengimpor library luar selain `<iostream>`.

## Daftar File
- `Perancangan_Logika_TLS26.pdf` : Dokumen perancangan algoritma Fase 1.
- `problem1.cpp` : Source code C++ solusi *Problem 1: The Last Astronaut*.
- `problem2.cpp` : Source code C++ solusi *Problem 2: Alien-In-The-Middle*.
